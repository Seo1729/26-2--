# 조작 키 설정

메인 메뉴의 **조작 키 설정** 또는 게임 중 **F1**에서 설정 화면을 연다.
게임을 선택하고 동작 버튼을 누른 다음 사용할 키 하나를 누른다.
ESC는 입력 취소이며, 중복·예약 키는 오류 메시지를 표시하고 기존 설정을 유지한다.
**이 게임의 기본 키로 초기화**는 선택한 게임의 키만 초기화한다.

일반 테트리스, 갤러그 협동, 똥피하기, 3D 테트리스 설정을 분리한다.
갤러그는 테트리스 동작과 전투기 동작 전체의 키 중복을 검사한다.
똥피하기는 두 플레이어와 일시정지·재시작 동작 전체를 검사한다.
각 게임에 실제 존재하는 동작만 제공한다. 3D에는 홀드 동작을 추가하지 않는다.

ESC, Tab, 수정 키(Shift/Ctrl/Alt/Meta/Windows/AltGraph), F1, F4,
컨텍스트 메뉴 키는 예약한다. 조합 키는 설정할 수 없다.
게임 진행은 설정 화면을 여는 동안에도 기존 타이머에 따라 계속된다.

`settings.GameControls`가 공유 `GameSettings`, 키 변환, 변경 알림과 저장을 관리한다.
음량 `Settings`도 같은 객체를 사용하므로 음량 저장 시 키 설정이 덮어써지지 않는다.
키 변경은 `GameControls.setKey`를 사용한다. 데이터 객체의 직접 setter는 입력 갱신이나
자동 저장을 수행하지 않는다.

기존 KeyListener는 실제 키를 중앙에서 기본 동작 키로 변환한 뒤 기존 동작을 실행한다.
똥피하기의 반복 간격과 갤러그의 연속 이동·발사는 유지한다.
키 변경 이후 입력 또는 다음 타이머 처리 전에 이전에 누른 키 상태를 비운다.
3D의 InputMap은 변경 알림 시 다시 등록하고 눌림 상태를 비운다.
설정 변경 API는 Swing EDT에서 사용하는 것을 권장한다.

사용자 홈의 `.jbnu-tetris/game-settings.properties`에 즉시 저장한다.
잘못된 키는 기본 키로 복구하며 중복이 생기면 해당 게임 전체를 기본값으로 복구한다.
저장이 실패해도 현재 실행에는 적용하고 화면에 실패를 표시한다.

`KeyBindingCheck`, `DodgeKeyCheck`로 충돌 방지, 실제 입력, 즉시 적용, 기본값 복원을
검증하며 `KeyBindingCheck reload`는 별도 JVM에서 재실행 복원을 검사한다.
테스트는 임시 사용자 홈(`-Duser.home`)을 지정해 실행한다.
