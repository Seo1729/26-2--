# 음량 설정

메인 메뉴의 **음량 설정**에서 배경음악과 효과음을 각각 0~100으로 변경한다.
0은 해당 종류의 소리를 즉시 멈춘다. 배경음악 음량을 다시 올리면 현재 위치에서
반복 재생하고, 멈춘 효과음은 다음 게임 이벤트에서 다시 재생한다.

`Settings.setBgmVolume(int)` / `Settings.setSfxVolume(int)`은 음량 적용과
`GameSettings` 파일 저장을 함께 수행한다. 저장 실패 시 게임은 계속되고,
설정 화면과 `Settings.getSaveError()`에서 실패를 알린다.
다른 코드에서 `GameSettings` 객체만 변경하는 것은 재생 음량을 변경하지 않는다.
키 설정은 기존 파일에 함께 보존되며 입력 처리에는 연결하지 않았다.

설정 파일은 사용자 홈의 `.jbnu-tetris/game-settings.properties`이다.
기존 Preferences 기반 `Settings` 대신 이 파일을 사용한다.
기존 전체 음소거 API도 파일의 `muted` 항목으로 저장한다.

기존 사운드는 22050Hz, 16비트 모노 PCM을 합성하고 효과음별 Clip을 재사용하며
BGM은 Clip 반복 재생을 사용한다. 이 합성 방식과 재생 호출 API는 유지한다.
`MASTER_GAIN`이 있으면 현재 Clip의 gain만 변경한다.
제어를 지원하지 않는 장치는 원본 PCM을 새 음량으로 조절한 뒤 Clip을 다시 열고,
현재 프레임 위치와 반복 여부를 복원한다. 같은 음량에서는 Clip을 재사용한다.
대체 경로에서 짧은 끊김이 생길 수 있으며, 장치를 열지 못하면 기존처럼
소리 없이 게임을 계속한다. 게임 이벤트에 새로운 소리 호출은 추가하지 않았다.

`SoundVolumeCheck`는 가짜 Clip으로 즉시 반영, 독립 음소거, BGM 재개,
효과음 재생 유지, PCM 대체 처리를 검사한다. `reload` 인수로 별도 JVM에서
저장된 음량 25/35 복원을 확인한다. 테스트는 임시 `-Duser.home`으로 실행한다.
